# Industrial Robotics: Digital Twin with 3D EMI Aura

This repo demonstrates how to use Arduino Uno Q (4G) to detect electromagnetic inference (EMI) hazards. Uno Q is a dual-brain solution, that has both MPU (Qualcom) and MCU (STM).

> [!NOTE]
> Qualcomm Arduino Uno Q (4G) was kindly provided by Hackster.io.
